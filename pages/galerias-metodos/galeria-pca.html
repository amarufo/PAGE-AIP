🎯 PCA

Análisis de Componentes Principales

Información del Método

  • Tipo: Reducción de dimensionalidad multivariada
  • Aplicable a: Matrices de correlación con variables múltiples
  • Estadístico: Eigenvalores, varianza explicada %
  • Frecuencia en tesis: 1 de 8 tesis (12.5%)
  • Ventajas: Reduce dimensionalidad, descubre patrones

Casos de Uso Recomendados

  • Creación de índices sintéticos a partir de múltiples indicadores
  • Simplificación de datasets con muchas variables correlacionadas
  • Identificación de patrones y agrupaciones naturales
  • Preparación de datos para otros algoritmos (regresión, clustering)
  • Descubrimiento de dimensiones latentes en datos complejos

Recursos Complementarios

  • Software Recomendado: R (prcomp, factoextra), Python (sklearn.decomposition), SPSS, Stata
  • Supuestos: Correlación entre variables, normalidad multivariada
  • Interpretación: Eigenvalores (varianza), loadings (contribución de variables)
